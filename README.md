## Safety and verification

A list entry does **not** mean a tool was installed, tested, license-cleared, or approved by organizers. Avoid unsupervised modifications to running services. Keep backups and test rollback. The handbook is for advance study and permitted references only; do not use AI during the event.

To run documentation locally: `pip install -r requirements.txt && mkdocs serve`.

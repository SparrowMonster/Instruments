# nethogs

**Уровень:** easy · **Статус:** справочный черновик, не протестировано на инфраструктуре соревнования.

## Что делает и для чего нужно

Потребление сети по процессам. Это помогает команде наблюдать за системой, диагностировать проблемы, принимать решения или поддерживать защиту. Использовать в зависимости от реальных сервисов и разрешений.

## Сценарии

- Первичный осмотр незнакомой инфраструктуры, если применимо.
- Проверка подозрительных событий и сравнение с обычной активностью.
- Контроль доступности до и после внесённых защитных изменений.
- Подготовка доказательств эффективности для технического отчёта.

## Установка / подготовка

```text
sudo apt install nethogs
```

Установка указана как пример для совместимых сред. Прежде чем выполнять, сверить поддерживаемую версию ОС и текущий upstream.

## Команды для быстрой диагностики

```bash
sudo nethogs
sudo nethogs -h
```

Для остальных параметров использовать локальный `--help` и официальную документацию. Некоторые команды предполагают, что сервис установлен или подготовлены тестовые файлы (например, sample.pcap).

## План применения

1. Определить критичные endpoints, службу, сеть и начальную доступность.
2. Проверить наличие бинарника, системные требования и права.
3. Использовать read-only наблюдение первым шагом.
4. При настройке блокировки выбрать безопасный режим наблюдения и протестировать на учебном окружении.
5. После каждого изменения проверить API/HTTP/TCP и необходимые функции приложения.
6. Зафиксировать найденные проблемы, ложные срабатывания, CPU/RAM, время реакции и изменения конфигураций.

## Риски

- Применимость зависит от ОС, версии, разрешённых прав и типа инфраструктуры.
- Ошибочные блокировки и изменения правил могут нарушить работу пользователей или скоринга.
- Результаты анализа и сигнатур требуют ручной проверки; не считать каждый alert доказательством атаки.

## Диагностика и откат

Проверь версию установленного компонента, лог службы, зависимости и права. До изменения конфигурации сохрани копию и путь возврата. При проблемах восстанови исходную конфигурацию, проверь синтаксис, верни допустимым способом и повтори health-check. Не удаляй журналы или артефакты расследования.
